# RoughChapel

RoughChapel implements a high-performance, distributed architecture for message-queueing and event-driven systems via a lightweight protocol module.

The key benefits of using RoughChapel include:

- RoughChapel implements a high-performance, distributed
- architecture for message-queueing and event-driven
- systems via a lightweight protocol

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughChapel.git`
2. `cd RoughChapel`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
